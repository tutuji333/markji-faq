# 修改过的卡片如何恢复？

## 简答

这件事的口径经历过一次变化：

- 早期：还不支持直接恢复
- 后来：网页端已经支持 `卡片编辑历史`

## 现在更应该先看哪里

论坛里展示的新能力是在官网网页端：

- 可以查看一张卡片的历史编辑记录
- 可以回看历史版本
- 可以把卡片还原到某个旧版本

如果你现在想找“恢复入口”，优先先去网页端找 `编辑历史` 会更靠谱。

## 需要注意什么

论坛里公开展示的是网页端能力。

如果你在移动端里没看到完全一样的入口，不一定是你操作错了，更可能是你找的端不对。

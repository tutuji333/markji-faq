# 学习、复习与选卡

这页集中处理论坛里关于学习量、反馈按钮、选卡逻辑和学习记录操作的高频问题。

## 常见问题

### 为什么一键选卡看不到

论坛里“一键选卡功能缺失”的官方回复可以先整理成这几个结论：

- 5.0 版本对学习设置和选卡逻辑做过调整
- 旧的整体批量添加入口被移除了
- 现在更偏向进入单个牌组后再做批量添加

所以，如果你是“更新后突然找不到一键选卡”，优先不要先判断成 bug，而是先确认：

- 是不是刚升级到 5.0 之后
- 是不是还在找旧版本的整体入口
- 当前是不是已经进入单个牌组内部

论坛回复里还提到：完全自动添加新卡的能力当时还没有正式上线，后续会以新选项的形式替代一部分手动选卡操作。

### 如何保证每日固定的新学量

论坛里的官方邮件口径比较明确：

- 当前还不支持单独设置“每日固定新学量”
- 现阶段更稳妥的做法是手动添加新卡，自己控制当天加入学习规划的数量

也就是说，如果你的目标是“复习照旧，但每天必须固定学 X 张新卡”，现在更接近“手动维持”，而不是“打开一个现成功能”。

### 为什么学习量看起来不对

常见原因包括：

- 今日新学量和手动超额加入不是一回事
- 复习上限可能影响新学表现
- 自动选卡和手动选卡的行为边界不同

更完整的解释请看[使用手册的学习与复习页](https://tutuji333.github.io/markji-manual/study-review/)。

### 为什么现在要逐个牌组改每日学习量

论坛里有用户专门提过这个变化。当前比较稳妥的理解是：

- 旧版存在更集中的调整入口
- 近期版本把学习量调整更偏向牌组级别
- 如果你是为了“快速完成签到”才想统一降学习量，这更像一个尚未完全解决的需求，不是你没找到按钮

### `认识 / 模糊 / 忘记 / 熟知` 应该怎么选

先按真实记忆状态选，不要按“想让算法怎么安排”倒推。

- `认识`：当前能回忆
- `模糊`：能想起但不稳
- `忘记`：当前没回忆出来
- `熟知`：已经完全掌握

### 如果我每次都先背熟，再一直点“认识”，可以吗

论坛里这类问题讨论很多，但官方口径很稳定：

- 软件依赖的不只是间隔重复，还有主动回忆
- 如果你每次都先背熟再点“认识”，算法会误以为你掌握得比实际更好
- 这样可能把下一次复习排得过远，反而不利于长期记忆

更稳妥的做法是：

1. 先看题目，独立回忆
2. 再看答案
3. 按你看到题目时的真实记忆状态反馈

### 模糊完成复习是什么意思

论坛里的官方解释可以整理成这样：

- 关闭时：一直点“模糊”不能完成当天复习，通常要点到“认识”为止
- 开启时：即使点“模糊”，也可以完成当天复习

官方更推荐关闭这个选项，因为当前算法更希望你在真正掌握后再给出“已掌握”的反馈。

### 如何暂停复习某个牌组

论坛里给出的稳定方法是：

- 进入这个牌组的设置页
- 把这个牌组的 `每日学习量` 调整为 `0`

这样通常可以达到“暂停复习”的效果，同时保留牌组和学习记录，不需要直接删除牌组。

### 重置数据和移除记忆有什么区别

论坛里目前比较清楚的区分是：

- `重置学习数据`：清掉整个牌组相关的学习记忆行为，让牌组回到“从未学习过”的状态
- `移出记忆`：把卡片从当前学习规划里移出，不再安排复习，但保留之前的学习记录

如果你的目标是“从头重新学整个牌组”，更接近重置。  
如果你的目标只是“先不学这批卡，但保留历史记录”，更接近移出记忆。

这两个动作对学习记录的影响差别很大，所以在你还没完全确认前，不建议随手操作。

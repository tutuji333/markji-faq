# 为什么一键选卡不见了？

## 简答

这不是你没找到，而是 `5.0` 调整了学习设置和选卡逻辑，旧的全局 `一键选卡` 入口被隐藏了。

## 这次变化到底改了什么

官方在 `5.0` 预告里说得比较明确：

- 旧的 `我的 -> 每日学习量` 入口被隐藏
- 旧的 `牌库 -> 一键选卡` 入口也被隐藏
- 设置入口迁到具体牌组右侧 `⋮ -> 学习设置`

也就是说，学习量和选卡不再走一个全局总入口，而是回到每个牌组内部处理。

## 现在该去哪里

如果你想改学习量或新学 / 复习安排：

1. 找到目标牌组
2. 点右侧 `⋮`
3. 进入 `学习设置`

如果你想补加卡片，当前口径是：**进入单个牌组内操作**，而不是再走过去的总入口。

## 现在还有没有“完全自动添加新卡片”

论坛里较新的官方回复是：**当前还不支持完全自动添加新卡片**。

目前更接近的做法是：

- 在单个牌组内做批量添加 / 选卡
- 等后续更完整的自动化方案上线

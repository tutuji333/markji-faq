# 导入、导出与创作

这页处理创作、导入和导出相关的高频问题。

## 常见问题

### 导入 `apkg` 提示“文件解析失败，请更换其他文件”

优先检查：

- 文件本身是否损坏
- 文件来源是否可靠
- 当前平台和版本是否支持该导入路径

如果继续失败，请到[故障排查](troubleshooting.md)看需要准备哪些信息。

### `apkg` 导入后乱码怎么办

这类问题通常和源文件结构、内容编码或支持范围有关。

建议准备：

- 示例文件
- 平台和版本号
- 导入前后截图

### PDF 导出不完整怎么办

先确认：

- 是否和图片、公式、长内容有关
- 是否只在某一端发生
- 导出前预览是否正常

### 我应该用可视化编辑器还是语法编辑器

如果你只是做第一张卡，先用可视化编辑器。  
如果你需要更复杂的结构、公式、引用和排版，再看语法编辑。

完整说明请看[使用手册的创作与导入导出页](https://tutuji333.github.io/markji-manual/creation-import/)。

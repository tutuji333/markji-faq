# 专业版、记忆币与升级

这页集中回答论坛里最常见的一组问题：专业版是什么、终身会员怎么升级、记忆币规则怎么看、为什么有些入口后来改了。

## 专业版到底是什么

从论坛里反复出现的稳定口径来看，基础版仍然可以继续使用，但专业版会提供更多记忆相关能力、权益和后续扩展功能。

如果你想看更系统的正式说明，请去[使用手册的专业版与权益说明](https://tutuji333.github.io/markji-manual/pro-membership/)。

## 终身会员如何升级 {#lifetime-upgrade}

论坛里的官方邮件口径是：

1. 在 App 里进入 `我的`
2. 点击右上角的 `礼物` 图标
3. 进入 `福利活动`
4. 在活动详情里看升级规则

当前论坛给出的明确条件之一是：专业版剩余天数需要大于 `999` 天。

如果你在当前版本里找不到这个入口，优先确认：

- 现在使用的是不是 App 端
- 当前账号是否已开通专业版
- 当前剩余天数是否满足活动条件

## 学习收藏牌组消耗减免是什么意思 {#collected-deck-discount}

论坛里的官方解释可以整理成一句话：

- 学习自建牌组：专业版可免消耗
- 学习收藏牌组：专业版不是免消耗，而是消耗减半

也就是说，如果你学习的是系统里搜索并收藏来的他人牌组，开通专业版后通常仍然需要消耗记忆币，只是比基础版少。

## 为什么不能自己设置牌组学习消耗

论坛里目前比较稳定的口径是：

- 以前“修改牌组学习消耗”是测试功能
- 这个测试功能后来被关闭
- 当前统一标准下，普通牌组的学习消耗通常按系统规则处理

论坛回复里还提到，后续版本计划探索更完整的牌组交易或定价能力。但在正式功能上线前，不建议把旧测试入口当成当前正式能力来理解。

## 专业版到底包含哪些功能

目前论坛里能反复看到、而且相对稳定的几项包括：

- 可重置学习数据
- 可查看单张卡片的复习周期
- 学习自建牌组免消耗
- 学习收藏牌组减半消耗

至于“更大空间”“更多福利”“后续版本能力”，论坛里也有一些阶段规划和讨论，但这部分变化性更大。更稳妥的做法是：

1. 先看当前应用内购买页和活动页
2. 再看使用手册的权益说明
3. 如果你要基于某个权益做购买决定，优先以当前产品页实际展示为准

## 我买了专业版，是不是就不花记忆币了

不是。

至少从当前论坛已知口径看，专业版对不同学习场景的影响不同：

- 自建牌组：通常免消耗
- 收藏牌组：通常减半，不是免除
- 其他活动、奖励、福利：以当前产品页口径为准

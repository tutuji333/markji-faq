# 牌组、卡片与管理

这页集中回答牌组整理、单卡管理、收藏牌组和编辑历史相关的问题。

## 常见问题

### 能不能把一张卡片直接移到另一个牌组里

根据论坛里“如何把一张卡片移到另一个牌组”的官方回复，当前版本并不支持直接跨牌组移动单张卡片。

这意味着：

- 你现在不能直接把单卡从 A 牌组挪到 B 牌组
- 复制粘贴到新牌组时，学习历史通常不会被一起保留
- 这更像当前版本能力边界，而不是你没找到入口

### 如何把牌组移动到另一个文件夹

论坛里的官方口径是：

- 在牌组列表页长按要移动的牌组
- 直接拖拽到目标文件夹上
- 松手即可完成移动

如果你是“以为不支持”，优先先试一下长按拖拽。

### 收藏牌组能不能自由编辑、增删改

论坛里当前比较稳定的结论是：

- 你可以修改其中卡片的内容
- 但暂时不能直接在原收藏牌组里增删卡片

如果你需要补充自己的知识点，更稳妥的做法是新建自己的牌组，把补充卡片单独加进去。

### 收藏牌组在原作者删除后会不会消失

论坛里的官方解释比较明确：

- 收藏牌组后，你这边会有一个独立备份
- 如果原作者后续更新或删除，系统会提醒你发生了变化
- 你可以选择不同步更新

也就是说，只要你不接受会破坏当前学习内容的更新，你通常仍然可以继续学习已有版本。

### 修改过别人的卡片后，怎么复原

这件事在论坛里经历过两个阶段：

- 较早时，官方口径是“暂不支持直接复原”
- 后续又上线了 `卡片编辑历史`

更稳妥的理解是：

- 如果你当前版本支持卡片编辑历史，可以查看历史记录并回到较早版本
- 如果你当前页面还没看到这个功能，先确认是否已经更新到较新的版本，并优先在网页端查看

### 别人的卡牌图片，能不能做遮盖编辑

论坛里的经验和官方回复都更偏向同一个结论：

- 手机上二次编辑图片遮盖会比较不便
- 更适合在网页端处理

如果你要做这类精细编辑，优先尝试网页端。

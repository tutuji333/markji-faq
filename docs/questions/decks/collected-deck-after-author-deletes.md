# 收藏牌组在原作者删除后会消失吗？

## 简答

不会直接跟着消失。

论坛里的官方邮件解释是：你收藏别人牌组时，系统会为你保留一个独立备份。

## 真正会影响你的是什么

影响你的不是“作者删了牌组”，而是你要不要同步这次更新。

官方给出的当前逻辑是：

- 原作者后续有更新或删除，你会看到更新提醒
- 你可以自己决定要不要同步
- 如果你不更新，就能保留你收藏时的那个版本继续学习

## 一个很容易漏掉的补充

论坛后来的补充还明确了一点：

- 如果你**接受更新**
- 而作者在这次更新里**删除了某张卡**
- 那么这张卡在你这里也会被删掉，**哪怕你之前做过二次编辑**

所以更稳妥的理解不是“我这里永远有一份完全独立的私有版本”，而是：

- 你**不更新**，就能保留收藏时的版本
- 你**接受更新**，就要一起接受这次更新里作者的删除动作

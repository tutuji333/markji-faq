# 我该去哪里求助

这页对应 Anki FAQ 里 “Getting Help” 那一类入口页。它不负责讲完整功能，而是先帮你判断应该去哪。

## 先判断你遇到的是哪类问题

先看[使用手册](https://tutuji333.github.io/markji-manual/)。

优先对应这些章节：

- 第一次使用：`快速开始`

- 搜索、同步与多端：`搜索、同步与多端使用`
- 权益说明：`专业版与权益说明`

### 我只是想快速确认一个短问题

先看 FAQ。

### 我已经遇到报错、失败、异常或明显不符合预期的行为

先看[故障排查](troubleshooting.md)。

如果已经是软件异常，优先走应用内的“异常反馈”，不要只停留在论坛发帖。

## 为什么异常优先走应用内反馈

论坛里“签到失败”等异常帖反复强调一件事：应用内异常反馈更适合真正的 bug 排查，因为它通常能自动附带设备和运行信息。

### App 内路径

- `我的 -> 帮助与反馈 -> 异常反馈`

### 网页端路径

- `右下角 -> ? -> 异常反馈`

## 论坛、邮件、Issue 和异常反馈分别适合什么

- 论坛：互助讨论、经验分享、资源交流、功能许愿
- 邮件：需要人工协助、账号问题、需要发源文件给官方
- GitHub Issue：文档错误、说明缺失、FAQ 需要补充
- 应用内异常反馈：软件异常、报错、闪退、行为异常

## 反馈前建议准备这些信息

- 当前平台和版本号
- 问题发生路径
- 截图或录屏
- 是否可稳定复现
- 是否和导入文件、牌组、账号或同步有关

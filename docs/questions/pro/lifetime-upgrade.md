# 终身会员如何升级？

## 简答

论坛里较新的官方邮件口径是：

路径：`我的 -> 右上角礼物图标 -> 福利活动`

同一封邮件里提到的升级条件是：`专业版剩余天数大于 999 天`。

## 这页最需要知道的两点

- 实际升级动作发生在 App 内的 `福利活动`
- 具体规则以活动页当时写明的条件为准，不要把单条帖子里的数字直接当成永久固定规则

## 为什么不要把它看成长期固定规则

论坛里另一个官方回复明确说过：`终身卡` 并不是计划长期开放的选项，它更接近某一阶段的福利活动。

这意味着：

- 入口在 App 内，不在官网直接售卖页
- 升级条件可能会随活动策略变化
- 看到旧帖子时，要优先以当前活动页说明为准

## 论坛里还出现过的旧升级思路

更早的帖子里，官方还给过一条“官网买记忆币 -> App 内福利兑换年卡 -> 再升级终身”的路径。

这能说明：论坛里关于终身升级，长期一直都是围绕 `福利活动 / 福利兑换` 这一套入口展开的。

## 官方给过的一个建议

多条官方回复里都提到过：通常不建议一开始就直接冲终身，更建议先用更短周期的会员确认自己是否真的适合这套产品。

# “新学受复习上限影响”表现不对怎么办？

## 先判断是不是这类问题

如果你遇到的是：

- 这个开关打开后，只会复习，不会新学
- 不管复习量有没有超过上限，新学都不出来
- 你的理解和页面说明明显对不上

这页更适合你。

## 论坛里的当前结论

安卓 `5.0` 上，这个开关曾经有过已知问题。

论坛里后续明确给出的修复版本是：`5.1.0`

## 现在最稳妥的处理方式

1. 先升级到 `5.1.0` 或更高版本
2. 在升级前，如果这个问题已经影响你的学习计划，先把该开关关闭

官方在问题修复前给出的过渡建议也是：先保持关闭，避免影响每天的新学和复习安排。

## 如果升级后还是不对

那就不要再当成“自己理解错了”，直接按异常处理：

- App：`我的 -> 帮助与反馈 -> 异常反馈`

提交时最好带上：

- 版本号
- 具体牌组
- 开关状态
- 你设定的新学 / 复习上限
- 录屏或截图

# 如何尽量保证每天都有固定新学？

## 简答

`5.0` 之后，主方法已经不是“手动补新卡”，而是到具体牌组的 `学习设置` 里分别设置 `每日新学上限` 和 `每日复习上限`。

如果你的目标是“复习照常，但每天也尽量推进新卡”，通常要重点检查 `新学受复习上限影响` 这个开关。

## 你真正需要知道的几件事

- `5.0` 起，学习量设置改成按牌组独立管理
- 旧的全局学习量入口和 `一键选卡` 入口因此被隐藏
- 关闭 `新学受复习上限影响` 后，新学和复习会变成两个独立任务池
- 开启该按钮时，如果当天待复习量超过复习上限，系统可能不会再安排新学

## 旧答案为什么不该继续当主答案

论坛里早期常见过一种旧口径：如果想保证每天都有新学，就靠手动添加新卡片。

这条回答对应的是 `5.0` 之前的过渡阶段。现在它最多只能算补充办法，不应该再作为当前主答案。

## 你可以怎么做

1. 进入目标牌组右侧 `⋮`
2. 打开 `学习设置`
3. 分别设置 `每日新学上限` 和 `每日复习上限`
4. 如果你希望复习再多也尽量每天安排新学，优先检查 `新学受复习上限影响` 是否关闭
5. 如果这个开关的表现和描述不一致，先升级到 `5.1.0` 或更高版本

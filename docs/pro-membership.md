# 专业版与记忆币

这部分只收 `专业版是什么`、`记忆币规则怎么变了`、`升级/权益/容量/语音额度` 这些高频问题。

!!! note "口径说明"
    专业版、记忆币和容量相关规则最近仍在迭代。尤其是 `2026-05-14` 之后，论坛前瞻已经把方向改成“基础学习尽量免费、专业版回归高级工具、记忆币更多负责内容交易与权益兑换”。正文里如果同时出现“旧商业模式口径”和“方向性预告”，请优先看日期更近的官方公告。

## 先理解现在这页在回答什么

- 如果你想问 `专业版到底是什么`：当前更稳的理解是，它正在从“学习免消耗权益”逐步转向 `高级工具集合`
- 如果你想问 `不买还能不能用`：论坛最新方向不是“基础版什么都不能做”，而是尽量降低基础学习摩擦
- 如果你想问 `为什么我看到的新旧说法不一样`：多半是因为论坛最近正处在商业模式过渡期

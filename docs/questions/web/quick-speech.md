# 如何快速生成语音？

## 简答

论坛里目前更常见的实际用法是：

- 移动端：先选中文本，再走 `发音 -> 合成语音`
- 网页端：选中文本后，用快捷键
  - Windows：`Ctrl + 5`
  - macOS：`Cmd + 5`

## 为什么很多人更推荐网页端

因为网页端做连续编辑时更顺手：

- 选中文本更快
- 快捷键直接触发
- 批量处理时不需要每次都走完整按钮路径

## 一个容易忽略的细节

论坛里还有个很实用的经验：

- 网页端快捷键会调用你 `上一次手动选择过的语音模型`

如果你发现网页端生成出来的声音不对，先手动生成一次，并确认当前使用的是你想要的语音模型，再继续用快捷键。

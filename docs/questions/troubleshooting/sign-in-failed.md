# 签到失败或按钮异常怎么办？

## 先判断是哪一类问题

先把这两种情况分开：

- `功能理解问题`：比如找不到补签按钮、想知道提前签到有什么用
- `真正异常`：比如签到失败、只有某个端签不了、行为明显不符合预期

如果你是第一种，先看：

- [补签按钮在哪里？补签卡怎么用？](../sign-in/make-up-sign-in.md)
- [提前签到有什么用？](../sign-in/early-sign-in.md)

## 如果是真正异常

论坛里的处理口径很一致：**优先走异常反馈，不要只停留在论坛发帖。**

路径：

- App：`我的 -> 帮助与反馈 -> 异常反馈`
- 网页端：右下角 `?` -> `异常反馈`

## 为什么要这样处理

因为签到失败通常需要结合：

- 设备信息
- 版本号
- 具体异常截图
- 是否跨设备复现

这些信息论坛里拿不到，异常反馈才更适合做真正排查。

# 选择题怎么加答案解析？

## 简答

目前更稳的做法是：**在选择题下面添加答案线，把解析写在答案线下面**。

这样复习时，选择答案后，答案线下方的内容会跟着显示出来，可以用来放正确答案说明、错因分析或解题思路。

## 具体怎么放

可以按这个思路组织卡片：

1. 上面放选择题题干和选项。
2. 在选择题下面添加答案线。
3. 把解析内容写在答案线下面。
4. 复习时确认选择后，再查看答案线下的解析内容。

论坛里 [topic 738](https://markji.discourse.group/t/topic/738) 的互助答复就是这个口径：在选择题下面添加答案线，确认选择之后，答案线下的内容会展现，所以可以把解析写在答案线下面。

## 能不能选择答案后自动显示解析？

从最近几条讨论看，用户希望的是：选择答案之后，不论对错都直接显示 `答案 + 解析`，不用再多点一次。

但 [topic 743](https://markji.discourse.group/t/topic/743) 里的现有解法仍然是：复习选择题时，可以点击选项下方的 `点此显示答案`，答案及后续解析会同步呈现。

所以当前可以这样理解：

- `能做解析`：可以，把解析写在答案线下面。
- `能复习时看到解析`：可以，选择或显示答案后会看到答案线下内容。
- `是否已有一选完就自动展开解析的独立功能`：公开讨论里还不能确认已经支持，更像是功能优化建议。

## 相关提醒

如果你发现解析没有正常显示，先检查答案线本身有没有写对，尤其是行尾空格、换行位置这类细节。

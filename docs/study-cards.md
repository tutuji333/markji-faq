# 学习、复习与选卡

这页处理学习过程里的高频问答。

## 常见问题

### 为什么一键选卡看不到 {#missing-quick-select}

论坛里“一键选卡功能缺失”的官方回复可以先整理成这几个结论：

- 5.0 版本对学习设置和选卡逻辑做过调整
- 旧的整体批量添加入口被移除了
- 现在更偏向进入单个牌组后再做批量添加

所以，如果你是“更新后突然找不到一键选卡”，优先不要先判断成 bug，而是先确认：

- 是不是刚升级到 5.0 之后
- 是不是还在找旧版本的整体入口
- 当前是不是已经进入单个牌组内部

论坛回复里还提到：完全自动添加新卡的能力当时还没有正式上线，后续会以新选项的形式替代一部分手动选卡操作。

### 为什么学习量看起来不对

常见原因包括：

- 今日新学量和手动超额加入不是一回事
- 复习上限可能影响新学表现
- 自动选卡和手动选卡的行为边界不同

更完整的解释请看[使用手册的学习与复习页](https://tutuji333.github.io/markji-manual/study-review/)。

### `认识 / 模糊 / 忘记 / 熟知` 应该怎么选

先按真实记忆状态选，不要按“想让算法怎么安排”倒推。

- `认识`：当前能回忆
- `模糊`：能想起但不稳
- `忘记`：当前没回忆出来
- `熟知`：已经完全掌握

### 重置数据和移除记忆有什么区别 {#reset-vs-remove}

论坛里目前比较清楚的区分是：

- `重置学习数据`：清掉整个牌组相关的学习记忆行为，让牌组回到“从未学习过”的状态
- `移出记忆`：把卡片从当前学习规划里移出，不再安排复习，但保留之前的学习记录

如果你的目标是“从头重新学整个牌组”，更接近重置。  
如果你的目标只是“先不学这批卡，但保留历史记录”，更接近移出记忆。

这两个动作对学习记录的影响差别很大，所以在你还没完全确认前，不建议随手操作。

### 能不能把一张卡片直接移到另一个牌组里

根据论坛里“如何把一张卡片移到另一个牌组”的官方回复，当前版本并不支持直接跨牌组移动单张卡片。

这意味着：

- 你现在不能直接把单卡从 A 牌组挪到 B 牌组
- 复制粘贴到新牌组时，学习历史通常不会被一起保留
- 这个限制更像当前版本能力边界，而不是你没找到入口

如果你遇到的是“为什么操作不到”，先按“当前不支持”理解会更接近事实。

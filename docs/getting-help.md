# 常见问题总览

这页对应“我该先去哪里求助”的入口说明。

## 先判断你遇到的是哪类问题

### 1. 不确定功能入口在哪

先看[使用手册](https://tutuji333.github.io/markji-manual/)对应章节：

- 第一次使用：`快速开始`
- 学习与复习：`学习与复习`
- 创作与导入导出：`创作与导入导出`
- 牌组与协作：`牌组与协作`
- 同步与多端：`搜索、同步与多端使用`

### 2. 想快速确认一个短问题

先看本 FAQ 站点。

典型问题包括：

- 终身会员如何升级
- 为什么看不到一键选卡
- 重置数据和移除记忆有什么区别
- 学习收藏牌组消耗减免是什么意思

### 3. 已经出现异常或失败

直接看[故障排查](troubleshooting.md)。

## 如果还没有答案

你可以按这个顺序反馈：

1. 提交 Issue
2. 发邮件
3. 去论坛讨论

## 反馈前建议准备

- 当前平台和版本号
- 问题发生路径
- 截图或录屏
- 是否可稳定复现
- 是否和导入文件、牌组、账号或同步有关

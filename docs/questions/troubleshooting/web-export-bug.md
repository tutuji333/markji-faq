# 网页功能或导出异常怎么办？

## 先判断是不是这类问题

如果你遇到的是下面这些现象，这页更适合你：

- 网页端按钮一直转圈，但没有结果
- PDF 导出没有文件
- 网页端新建卡片位置异常
- 某个网页功能表现明显不对

## 这类问题先不要当成普通问答

论坛里关于 `PDF 导出不完整 / 导出按钮转圈 / 网页功能异常` 的公开讨论很多，但稳定、明确的官方修复口径并不统一。

所以这类问题更接近真正的网页异常，最重要的不是猜，而是把复现条件准确交给官方。

## 提交前最好准备这些信息

- 浏览器名称和版本
- 设备型号或系统版本
- 复现步骤
- 截图或录屏
- 如果和导入文件有关，保留原文件

## 更稳妥的反馈入口

- 官方服务指南里更稳定的口径，是先走 App 内 `异常反馈`
- 如果问题和具体文件、导出结果有关，也可以补发到 `support@markji.com`
- 论坛的其他讨论里也出现过网页端 `? -> 异常反馈` 的说法；如果你当前网页端确实能看到这个入口，也可以直接提交

## 论坛里出现过的自助排查思路

这些更接近社区排查经验，不是官方保证有效的万能修复：

- 检查浏览器下载权限和默认下载目录
- 试试切换浏览器或桌面模式
- 重试一次，或换网络再试

如果这些都没解决，就不要继续猜，直接提交异常信息。

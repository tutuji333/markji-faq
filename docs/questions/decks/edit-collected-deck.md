# 收藏牌组可以自由增删改吗？

## 简答

目前的口径是：

- `改内容`：可以
- `直接在原收藏牌组里加卡 / 删卡`：不可以

## 这意味着什么

如果你收藏的是别人做的牌组，你可以对卡片内容做自己的修改，但还不能把它当成你自己的原始牌组那样，随意往里新增卡片或直接删除原有卡片。

## 如果你确实需要补内容

论坛里的官方建议更偏向：

- 自己新建一个牌组
- 把需要补充或单独强化的知识点加进去

也就是说，当前更适合“原牌组继续学，补充内容另开一组”，而不是把收藏牌组直接改造成你自己的完整版本。

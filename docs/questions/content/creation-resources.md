# 制卡语法、视频教程和创作者资料去哪里找？

## 简答

如果你现在最缺的是“做内容时该先看什么”，论坛里目前最值得先看的不是单条答疑，而是 4 类入口：

- `制卡语法文档入口`
- `官方视频指南合集`
- `创作者与制卡帖子整理`
- `官方创作公告与精选牌组标准`

## 如果你只想先看 4 个入口

1. [topic 407](https://markji.discourse.group/t/topic/407)：最适合拿来找制卡语法文档入口  
   论坛里直接给出了飞书文档跳转。
2. [topic 713](https://markji.discourse.group/t/topic/713)：官方视频指南合集  
   适合刚开始做牌组、想看演示操作的人。
3. [topic 654](https://markji.discourse.group/t/topic/654)：创作者及制卡相关帖子整理  
   更像一份“内容制作资料导航”。
4. [topic 546](https://markji.discourse.group/t/topic/546)：创作公告与精选牌组指南  
   这里既有创作者福利信息，也有官方明确写出的高质量制卡标准。

## 你可以按场景找资料

### 我想查具体语法

- 论坛在 [topic 407](https://markji.discourse.group/t/topic/407) 里给出的高频跳转地址是：  
  <https://maimemo.feishu.cn/docs/doccnjbGpf4ke3sU9U9jsuphwKE>
- 如果你关心的是 `加粗 / 颜色 / 背景` 这类组合格式，论坛里的更常见建议是先看语法文档，再优先用网页端可视化编辑处理，见 [topic 91](https://markji.discourse.group/t/topic/91)。
- 如果你卡在 `[]` 和格式语法冲突，论坛互助里有个很常用的替代方案：把正文里的半角括号改成全角 `［］`，见 [topic 53](https://markji.discourse.group/t/topic/53)。

### 我想看更直观的视频

- [topic 713](https://markji.discourse.group/t/topic/713) 目前已经把官方公开的视频指南做成合集。
- 其中最适合新手的一条，是 [topic 481](https://markji.discourse.group/t/topic/481) 对应的“答案线教程 + 在官网新建牌组”。
- 如果你是第一次做问答卡，先看视频通常比先啃零散答疑更快。

### 我想知道高质量牌组是按什么标准做出来的

论坛里目前最清楚的一份官方口径，是 [topic 546](https://markji.discourse.group/t/topic/546)：

- 强调 `主动测试`
- 强调 `知识点原子化`
- 建议 `一张卡片最多一条答案线`
- 建议同一牌组保持格式一致

如果你更想看社区经验，可以接着看 [topic 41](https://markji.discourse.group/t/topic/41) 和 [topic 654](https://markji.discourse.group/t/topic/654)。

### 我想知道创作者入口和后续机制

- `牌组自荐` 的论坛公开说明可以先看 [topic 302](https://markji.discourse.group/t/topic/302)。
- `创作者如何回复使用者反馈` 目前论坛里更常见的现实做法是留邮箱，或在牌组里单独做一张 Q&A / 更新日志卡片，见 [topic 455](https://markji.discourse.group/t/topic/455)。
- [topic 546](https://markji.discourse.group/t/topic/546) 里还提到过 `牌组版本管理`、`批量编辑`、`开放 API` 等创作者能力方向，但这些更适合理解路线图，不要当成已经全部落地的现成功能。

## 一句建议

如果你只是要“先做出一套能用的内容”，最省时间的顺序通常是：

1. 先看视频或语法入口
2. 先做最简单的一种卡型
3. 做熟以后，再补公式、语音、批量编辑这些高阶能力

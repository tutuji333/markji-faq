# 网页功能或导出异常怎么办？

## 先判断是不是这类问题

如果你遇到的是下面这些现象，这页更适合你：

- 网页端按钮一直转圈，但没有结果
- PDF 导出没有文件
- 网页端新建卡片位置异常
- 某个网页功能表现明显不对

## 先不要把它当成普通问答

这类问题更像真正的网页异常。

论坛里对于网页 bug、签到异常、导入异常这类情况的共通处理口径是：**优先走异常反馈**，而不是只在论坛里描述现象。

## 提交前最好准备这些信息

- 浏览器名称和版本
- 设备型号或系统版本
- 复现步骤
- 截图或录屏
- 如果和导入文件有关，保留原文件

## 更稳妥的反馈入口

- 网页端右下角 `?` -> `异常反馈`
- 如果问题和具体文件有关，也可以补发到 `support@markji.com`

## 这页不直接给“万能修复步骤”的原因

目前论坛里关于 `PDF 导出不完整 / 导出按钮转圈 / 网页异常` 的公开讨论很多，但稳定、明确的官方修复口径并不一致。

所以这类问题最重要的不是猜，而是把复现条件准确交给官方。

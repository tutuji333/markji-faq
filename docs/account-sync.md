# 账号、同步、签到与反馈

这页集中回答账号、登录、同步、换设备、签到和异常反馈路径相关的问题。

## 常见问题

### 手机端无法登录怎么办

先确认：

- 当前使用的平台
- 登录方式有没有变化
- 网络是否正常
- 是否刚切换过设备或账号

如果已经出现明确报错，请继续看[故障排查](troubleshooting.md)。

### 牌组内容和学习记录是不是一回事

不是。

- 牌组内容更接近资源内容本身
- 学习记录更接近你的个人学习进度

在当前已知资料里，学习记录同步比牌组内容同步更需要谨慎理解。尤其是你准备换设备、换账号、重置数据时，更不要把两者混成一回事。

### 换设备前最该注意什么

不要默认学习记录会完全自动实时同步，也不要把“能登录同一账号”和“所有学习数据都已安全同步”当成同一件事。

更稳妥的做法是：

1. 先确认老设备的同步状态
2. 再确认新设备登录的是同一账号
3. 大规模切换前先看[使用手册的同步说明](https://tutuji333.github.io/markji-manual/search-sync-multi-device/)

### 找回密码或切换验证方式怎么办

这类问题与账号入口和版本强相关，后续会继续根据需求文档补充更精确路径。

现在如果你已经卡住，建议优先通过邮件反馈并附上平台、版本和截图。

### 补签页面在哪里，补签卡如何使用

论坛里的官方口径是：

- 先完成当天学习计划
- 再进入签到页面
- 系统判断你符合补签条件时，才会显示 `补签` 按钮

也就是说，补签卡不是“买完立刻任意补”，而是要在签到日历页面满足条件后才能用。

### 签到失败应该去哪里反馈

论坛里这类异常的官方引导很一致：

- 软件异常、签到失败、行为异常：优先走 `异常反馈`
- 提建议：走 `功能许愿`
- 想找人工：走邮件
- 想让其他用户帮你看看：去论坛

真正要排查 bug 时，应用内异常反馈通常比论坛发帖更有效。

### 异常反馈路径是什么

`App 内`

- `我的 -> 帮助与反馈 -> 异常反馈`

`网页端`

- `右下角 -> ? -> 异常反馈`

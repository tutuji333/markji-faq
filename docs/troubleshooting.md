# 出现问题时先做什么？

如果你遇到的是失败、报错、闪退、同步不一致、导入异常或明显不符合预期的行为，先按这个顺序处理。

## 1. 先确认是不是版本问题

- 先看你当前的 App、网页端或系统版本
- 如果论坛里明确提到某个修复版本，先升级到那个版本再试
- 不要一边用旧版本，一边拿新口径判断行为是否正常

## 2. 先缩小问题范围

提交前最好先弄清楚：

- 只有一台设备出问题，还是所有设备都出问题
- 只有某个牌组 / 某个文件出问题，还是所有内容都出问题
- 是稳定复现，还是偶发
- 具体是在哪一步开始异常

## 3. 再决定走哪个处理入口

- `功能异常 / bug / 按钮不对 / 网页异常`：优先走 `异常反馈`
- `账号 / 登录 / 同步 / 文件迁移，需要人工协助`：优先邮件 `support@markji.com`
- `只是想看看别人怎么理解这个功能`：先看对应 FAQ，再去论坛

## 4. 提交前准备这些信息

- 平台、系统版本、App 版本
- 复现路径
- 截图或录屏
- 如果和导入有关，直接保留原文件
- 如果和账号有关，准备好注册账号

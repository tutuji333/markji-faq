# 重置学习数据和移出记忆有什么区别？

## 简答

两者最大的区别是：**会不会把历史学习记录一起清掉。**

- `重置学习数据`：清掉整个牌组的学习历史，回到完全没学过的状态
- `移出记忆`：只是先从当前学习规划里移走，不删除历史记录

## 什么时候适合用“重置学习数据”

如果你的目标是：

- 整个牌组从头来过
- 过去的学习记录不再保留
- 想把所有卡片恢复成未学习状态

那更接近 `重置学习数据`。

## 什么时候更适合“移出记忆”

如果你的目标是：

- 暂时不学某些卡
- 先把它们移出当前计划
- 以后再加回来时还能看到过去的反馈历史

那更接近 `移出记忆`。

## 一句话区别

- `重置`：清历史，重新开始
- `移出`：不安排了，但历史还在

# 当前支持 Markdown、表格、标题或代码块吗？

## 简答

如果你问的是“能不能像笔记软件那样，直接完整支持 Markdown / 表格 / 代码块 / 标题层级”，论坛里目前没有看到已正式落地的公开说明。

更稳妥的理解是：

- 墨记当前不是一款完整的 Markdown 笔记工具
- 官方公开定位仍然更偏 `间隔重复卡片学习`
- 这类能力在论坛里长期有人许愿，但不能当成已经上线

## 官方更明确的一点是什么

[topic 88](https://markji.discourse.group/t/topic/88) 里，官方对产品定位说得很清楚：

- 核心定位是 `基于间隔重复算法的卡片学习软件`
- 不是综合性的笔记软件
- 更推荐先在外部工具整理，再把知识点做成更原子化的卡片

所以如果你期待的是“把整篇 Markdown 笔记原样搬进来继续用”，这本来就不是当前最稳的主路径。

## 现阶段更现实的替代做法

### 1. 普通格式优先用可视化编辑

如果你只是想做：

- 加粗
- 颜色
- 背景

论坛里更常见的建议是：

- 先看语法文档入口
- 再优先用网页端可视化编辑处理

相关入口先看：

- [制卡语法、视频教程和创作者资料去哪里找？](creation-resources.md)

### 2. 表格内容

论坛里的官方临时建议比较明确：

- 可以先让 AI 或其他工具整理成表格
- 再把表格作为图片放进卡片

社区里也有人补过一种进阶做法：

- 用 `TeX / KaTeX array` 处理表格样式

但这更像技巧，不是通用可视化表格功能。

### 3. 标题层级

论坛里没有稳定公开的“一二级标题已支持”口径。

如果你只是想在卡片里制造一点视觉层级，社区里有人会用：

- 字号大小变化
- 公式语法做视觉区分

但从学习效果上，官方更推荐的是：

- 把内容拆得更原子化
- 不要让单张卡承载太多信息

### 4. 代码块

论坛里也能看到对代码显示的需求，但公开稳定口径仍然更接近：

- 这是许愿项
- 还不是现成功能

如果你急着用，现实做法通常是：

- 先在外部工具整理
- 再截图或简化成更适合记忆的卡片

## 一句话总结当前状态

- `完整 Markdown 兼容`：没有公开确认已落地
- `表格 / 标题 / 代码块`：论坛里持续有人想要，但更多仍是愿望
- `当前最稳工作流`：外部整理 + 原子化制卡 + 必要时用图片或公式语法替代

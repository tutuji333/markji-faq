# 考前冲刺时应该用练习模式还是提前复习？

## 简答

如果你想在考前高强度多刷几轮，但又不想打乱长期记忆安排，优先用 `练习模式`。

如果你是想把后面几天的卡片提前拉到今天来学，并接受后续规划被改动，才更适合 `提前复习`。

## 更适合用练习模式的情况

论坛里对 `练习模式` 的定位一直比较稳定：

- 更适合考前冲刺
- 更适合多轮速刷
- 不会直接打乱原本的长期记忆规划

[topic 27](https://markji.discourse.group/t/topic/27) 和 [topic 239](https://markji.discourse.group/t/topic/239) 里，官方都把它当成最优先推荐的冲刺工具。

## 更适合用提前复习的情况

论坛公开说明里，`提前复习` 更像是：

- 把未来会学到的卡片提前到今天处理
- 会影响后面的复习规划

按 [topic 239](https://markji.discourse.group/t/topic/239) 当时的官方说明：

- 入口在 `日历` 页
- 需要先完成当天任务
- 更像真正把后续任务往前挪，而不是额外练一遍

如果你看不到入口，论坛里更早的官方答复还提到过两件事：

- 先确认当天任务是否已完成
- 再确认版本是否已经覆盖到该功能

## 一个更稳的用法组合

论坛里更推荐的节奏，不是二选一，而是组合用：

1. 白天先完成正常的每日学习和复习
2. 晚上再用 `练习模式` 对重点内容多刷几轮
3. 临近考试时，如果还想把后面几天的内容往前提，再少量使用 `提前复习`

## 这两者最大的区别

- `练习模式`：更像加练
- `提前复习`：更像改计划

如果你只是怕考前忘，通常先上 `练习模式` 就够了。

## 目前论坛里还能确认的限制

- [topic 239](https://markji.discourse.group/t/topic/239) 里提到：练习模式当前不支持多设备同步练习进度
- 同一条讨论里更早的公开口径还提到：提前复习当时还不能精确指定某个牌组

这类细节后面可能会继续变化，所以如果你主要关心“入口还在不在”“现在还能不能指定牌组”，最好再结合最新版本实际界面确认。

# 如何暂停某个牌组的复习？

## 简答

论坛早期的官方邮件口径是：把这个牌组的 `每日学习量` 调成 `0`，就可以先停掉它，而不用删除牌组。

`5.0` 之后学习设置拆成了 `每日新学上限` 和 `每日复习上限`。如果你现在的目标是把整组先停掉，按当前设置逻辑，最稳妥的做法通常是把这两个上限都调到 `0`。

## 这样做的意义

- 不用删牌组
- 不会直接清掉学习记录
- 只是先停止系统继续给这组安排任务

## 适合什么场景

- 你最近不想碰这组内容
- 你想先把精力转去别的牌组
- 你只是想暂停，不是想重置学习历史

## 需要区分的另一件事

如果你真正想做的是“清掉历史，从头再学”，那不是暂停，而更接近：

- [重置学习数据](reset-vs-remove-memory.md)

## 说明

!!! note "口径说明"
    这条 FAQ 基于早期官方邮件口径和 `5.0` 后学习设置拆分逻辑整理。若你当前版本的入口名称不同，请以牌组里的 `学习设置` 为准。

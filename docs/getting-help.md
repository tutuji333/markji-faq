# 我该去哪里求助

这页对应 Anki FAQ 里 “Getting Help” 那一类入口页。目标不是把所有答案都堆在这里，而是先帮你判断：

1. 该看使用手册
2. 该看 FAQ
3. 该看故障排查
4. 该走应用内异常反馈

## 先分清你遇到的是哪类问题

### 我只是找不到入口，或者想知道“这个功能怎么用”

先看[使用手册](https://tutuji333.github.io/markji-manual/)。

优先对应这些章节：

- 第一次使用：`快速开始`
- 复习、学习量和选卡：`学习与复习`
- 导入、导出和制卡：`创作与导入导出`
- 账号、同步和多端切换：`搜索、同步与多端使用`
- 权益和版本差异：`专业版与权益说明`

### 我只是想快速确认一个短问题

先看本 FAQ 站点。

最常见的入口是：

- [学习、复习与选卡](study-cards.md)
- [牌组、同步与账号](account-sync.md)
- [专业版、记忆币与升级](pro-membership.md)
- [导入、导出与创作](import-export.md)

### 我已经遇到报错、失败、异常或明显不符合预期的行为

先看[故障排查](troubleshooting.md)。

如果已经是软件异常，优先走应用内的“异常反馈”渠道，而不是只在论坛发帖。

## 为什么异常优先走应用内反馈

根据论坛里“签到失败”等异常帖的官方处理口径，应用内异常反馈更适合真正的 bug 排查，因为它通常能自动附带设备和运行信息，排查效率也更高。

### App 内路径

- `我的 -> 帮助与反馈 -> 异常反馈`

### 网页端路径

- `右下角 -> ? -> 异常反馈`

## 论坛、邮件、Issue 分别适合什么

- 论坛：互助讨论、经验分享、功能许愿、案例交流
- 邮件：需要人工协助、账号问题、紧急问题
- GitHub Issue：文档错误、说明缺失、FAQ 需要补充
- 应用内异常反馈：真正的软件异常、报错、故障

## 反馈前最好准备这些信息

- 当前平台和版本号
- 问题发生路径
- 截图或录屏
- 是否可稳定复现
- 是否和导入文件、牌组、账号或同步有关

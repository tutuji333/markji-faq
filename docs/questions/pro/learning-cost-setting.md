# 为什么不能自己设置牌组学习消耗？

## 简答

论坛里的官方解释是：**用户自己改牌组学习消耗，曾经只是测试功能，现在已经关闭。**

当前统一标准下，普通牌组的学习消耗按系统规则处理，不再支持创作者自己改数字。

## 官方当前给出的解释

- 这项能力过去只开放给部分用户测试
- 随着系统升级和规则统一，测试功能已经收回
- 你现在看到自己的牌组消耗为 `1`，是当前统一标准，不是你没找到入口

## 这意味着什么

如果你现在找不到“修改牌组消耗”的地方，通常不是权限问题，而是这项入口本身就不再开放。

## 后面会不会完全没有定价能力

论坛里的较新回复提到：

- 未来更接近的方向是 `内容交易`
- 记忆币会更多转向 `牌组购买` 或 `兑换专业版等权益`
- 创作者更明确的定价能力，更像会出现在交易场景里，而不是现在这种“学习时随手改消耗数字”

也就是说，未来如果开放“价格”，更可能是商品化场景，而不是现在这种学习消耗数字随手改。

# “新学受复习上限影响”是什么意思？

## 简答

这个开关决定的是：当天复习积压时，系统还要不要继续给你安排新学。

- `关闭`：新学量和复习量是两个独立任务池
- `开启`：当日待复习量超过你设定的复习上限时，系统不再安排新学

## 官方当前更推荐哪种用法

论坛里的官方说明是：**更推荐关闭这个按钮**。

原因很直接：

- 关闭后，复习任务和新学任务互不挤占
- 更容易保证学习计划持续推进
- 你也更容易预估多久能学完一整个牌组

## 为什么它默认还是开启的

官方解释是：默认开启主要是为了兼容老版本用户的学习习惯。

也就是说，它更像一个“兼容旧逻辑”的过渡开关，而不是官方更推荐的新默认。

## 什么时候你会明显感觉到它在起作用

如果你把它打开了，同时当天待复习卡片已经超过复习上限，那么系统可能只给你复习，不再安排新学。

如果你的目标是“每天都要稳定推进新卡”，这通常就不是你想要的效果。

## 如果它表现得和描述不一样

安卓 `5.0` 曾经出现过已知问题：打开这个开关后，会出现“只复习、不新学”的异常表现。论坛里给出的修复版本是 `5.1.0`。

如果你遇到类似情况：

1. 先升级到 `5.1.0` 或更高版本
2. 在升级前，先把这个开关关掉，避免影响学习计划

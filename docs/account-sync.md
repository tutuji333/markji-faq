# 账号、同步与换设备

这页集中回答账号、登录、同步和多端切换相关的高频问题。

## 常见问题

### 手机端无法登录怎么办

先确认：

- 当前使用的平台
- 登录方式有没有变化
- 网络是否正常
- 是否刚切换过设备或账号

如果已经出现明确报错，请继续看[故障排查](troubleshooting.md)。

### 牌组内容和学习记录是不是一回事

不是。

- 牌组内容更接近资源内容本身
- 学习记录更接近你的个人学习进度

在当前已知资料里，学习记录同步比牌组内容同步更需要谨慎理解。

### 换设备前最该注意什么

不要默认学习记录会完全自动实时同步。

更稳妥的做法是：

1. 先确认老设备的同步状态
2. 再确认新设备登录的是同一账号
3. 大规模切换前先看[使用手册的同步说明](https://tutuji333.github.io/markji-manual/search-sync-multi-device/)

### 找回密码或切换验证方式怎么办

这类问题与账号入口和版本强相关，后续会继续根据需求文档补充更精确路径。

现在如果你已经卡住，建议优先通过邮件反馈并附上平台、版本和截图。

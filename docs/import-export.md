# 导入、导出与创作

这页处理论坛里与导入、导出、制卡和语音生成相关的高频问题。

## 常见问题

### 导入 `apkg` 提示“文件解析失败，请更换其他文件”

优先检查：

- 文件本身是否损坏
- 文件来源是否可靠
- 当前平台和版本是否支持该导入路径

如果继续失败，请到[故障排查](troubleshooting.md)看需要准备哪些信息。

### Anki 导入失败或乱码怎么办

论坛里目前能整理出的稳定结论是：

- 这类问题确实存在
- 有时会表现为“直接解析失败”
- 有时会表现为“勾选旧版本支持后能导入，但内容乱码”

官方在这类帖子里的处理方式很明确：

- 不再只让你自己反复试
- 直接把相关 Anki 文件发送到官方邮箱
- 让工程师具体排查并协助导入

所以如果你已经试过不同导出方式，仍然失败或乱码，最有效的下一步通常不是继续盲猜格式，而是直接把源文件发给官方排查。

### `apkg` 导入后乱码怎么办

这类问题通常和源文件结构、内容编码或支持范围有关。

建议准备：

- 示例文件
- 平台和版本号
- 导入前后截图

### PDF 导出不完整怎么办

先确认：

- 是否和图片、公式、长内容有关
- 是否只在某一端发生
- 导出前预览是否正常

如果你的问题是“只有部分卡片导出不完整”，比起先怀疑整个导出功能坏了，更值得先缩小样本，确认是否和个别卡片内容有关。

### 如何快速生成语音

论坛讨论里比较一致的做法有两种：

- 移动端：先选中文本，再从工具栏进入发音 / 合成语音
- 网页端：选中文本后，用快捷键快速合成语音

论坛里反复出现的网页端快捷键是：

- `Windows: Ctrl + 5`
- `macOS: Cmd + 5`

如果你要频繁做语音，网页端通常会更省时间。

### 网页端生成的语音和手机端为什么看起来不一样

论坛讨论里比较一致的判断是：

- 生成后的音频会作为媒体数据保存并同步
- 如果你感觉两个端口声音不一样，常见原因之一是所用语音模型不同
- 网页端快捷键常常会沿用你上一次手动生成时选择的模型

所以，如果网页端生成出来的声音不对，先手动确认一次当前语音模型，再继续用快捷键。

### 我应该用可视化编辑器还是语法编辑器

如果你只是做第一张卡，先用可视化编辑器。  
如果你需要更复杂的结构、公式、引用和排版，再看语法编辑。

完整说明请看[使用手册的创作与导入导出页](https://tutuji333.github.io/markji-manual/creation-import/)。

### 语法编辑里，方括号和加粗 / 颜色冲突怎么办

论坛讨论里给出的一个可行做法是：

- 不直接用普通半角方括号
- 改用视觉上接近的全角符号来规避语法冲突

这更像是当前语法边界下的规避方式，而不是一个特别优雅的正式语法能力。所以如果你经常遇到类似排版问题，更适合在网页端边预览边调整。

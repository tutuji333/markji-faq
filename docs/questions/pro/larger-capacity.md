# 专业版中的“更大容量”是什么意思？

## 简答

论坛里这条口径的核心是：容量按 `账号总量` 统计，而不是只看你是不是创作者或学习者。

统计范围包括：

- 字符串
- 图片
- 音频
- 账号下所有牌组相关资源

## 不要把它理解成什么

它不是只看：

- 某一个牌组
- 只看你上传的图片
- 只看创作者身份下的内容

按论坛里的解释，它看的是你账号整体占了多少内容资源。

## 还有一个要注意的点

当时论坛里的官方回复还提到：

- 系统一直存在容量限制
- 之前因为逻辑漏洞，触发限制后处理不够好
- 更明确的容量标准和后续优化，会放到 `5.0+` 阶段继续处理

所以如果你关心的是“当前精确上限到底是多少”，这条 FAQ 只能给你解释“它在算什么”，不能替代最新产品页或客服确认。

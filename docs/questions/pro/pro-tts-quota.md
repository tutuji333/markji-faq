# 专业版生成语音次数有什么变化？

## 简答

论坛里的官方邮件口径是：升级到 Pro 之后，**每日语音生成次数会比基础版高很多**。

## 这条 FAQ 能确认什么

可以确认的是：

- Pro 和基础版的差别，核心在于 `每日次数上限`
- 如果你经常做语音，Pro 的额度明显更宽松

## 这条 FAQ 不能确认什么

论坛这条公开口径没有给出一组固定数字，所以这页不写死具体次数。

如果你关心的是最新精确额度，最好以当前产品内页面或客服答复为准。

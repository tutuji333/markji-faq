# 网页端、搜索与编辑

这页集中整理网页端使用时最容易遇到的几个问题。

## 常见问题

### 网页端如何精准搜索

论坛里比较一致的经验是：

- 先用产品自己的搜索做初筛
- 再结合浏览器的 `Ctrl + F` / `Cmd + F` 做页面内精确查找

需要注意的是，网页端可能存在分页加载机制。浏览器自带查找只能搜到当前已经加载出来的内容。

### 为什么搜索结果会把词拆开，导致命中太多

论坛里的用户反馈表明，网页端搜索会更偏向模糊拆词，而不是强制按整句精确匹配。

所以，如果你想找的是非常具体的一张卡，单靠搜索框未必最省事，往往要配合浏览器页面查找一起用。

### 修改过的卡片，能不能看历史版本

论坛后续已经出现“卡片编辑历史”相关功能展示。更稳妥的理解是：

- 至少在较新的版本和网页端里，已经支持查看卡片编辑历史
- 也支持回到较早版本

如果你当前页面还没看到，优先确认：

- 当前是不是网页端
- 当前卡片是不是你有权限查看编辑历史的对象
- 当前版本是不是较新的版本

### 别人的卡牌图片，为什么在手机上不方便二次编辑

论坛里这类问题的答案很稳定：

- 手机端更适合学习和轻编辑
- 真要做图片遮盖、细排版或复杂编辑，网页端更方便

如果你在手机上怎么都找不到相应入口，先不要急着判断功能不存在，优先试试网页端。

### 网页端更适合做什么

结合论坛讨论，网页端更适合这些场景：

- 快速生成语音
- 看编辑历史
- 做图片遮盖
- 做复杂语法编辑
- 结合浏览器查找做精准定位

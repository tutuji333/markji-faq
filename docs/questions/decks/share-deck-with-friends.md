# 如何让好友免费学习共享牌组？

## 简答

按论坛里目前能看到的官方邮件口径，`没有` 这样一个创作者侧开关：

- 你不能手动把“别人学习你的牌组时的消耗”改成 0
- 也不能只对某些好友单独设成免费

如果你现在找不到这个入口，通常不是你没找到，而是它本来就不支持。

## 现在不能做什么

[topic 514](https://markji.discourse.group/t/topic/514) 的官方邮件讲得很直接：

- 目前不支持制卡人手动设置他人学习自己牌组时的消耗
- 也不支持直接做一个“给好友免费学”的共享开关

## 现在更现实的做法

论坛邮件里给出的现实方案，主要是这几类：

- 如果牌组量不大，让对方先用新用户赠送和活动福利体验
- 如果学习量很大，更实际的是评估专业版是否划算
- 如果你本身是创作者，别人学习你的牌组时，系统侧还会有创作激励这条线

也就是说，当前更接近的是“通过现有权益和活动降低成本”，而不是“直接设成免费”。

## 不要把它和另外两件事混在一起

### 1. “我能不能自己改牌组学习消耗”

这是另一件事。

[topic 585](https://markji.discourse.group/t/topic/585) 的官方回复说明：

- 创作者自己改学习消耗，曾经只是测试功能
- 现在已经关闭
- 当前看到的统一消耗，不代表你少了某个权限入口

### 2. “未来会不会有更明确的定价能力”

论坛较新的官方回复提到过：

- 后续更可能往 `牌组买卖 / 自由定价` 这类场景发展

但这类内容更适合理解方向，不应该当成“现在就已经有的共享开关”。

## 关于“校园计划”这类预告

[topic 514](https://markji.discourse.group/t/topic/514) 里，当时官方还提到过 `校园计划` 方向。

这类信息更适合当成：

- 当时的规划信号

而不是：

- 现在已经开放、可以立即申请的固定功能入口

## 一句话判断

- 想让好友“直接免费学你的共享牌组”：当前不支持
- 想调整他人的学习消耗：当前不支持
- 想看未来会不会有更明确的定价或交易：论坛里有方向性信号，但别当现成能力

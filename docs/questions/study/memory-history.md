# 如何查看卡片记忆历史与下次复习安排？

## 简答

如果你想看一张卡为什么会被安排到某一天、之前点过什么反馈，论坛里目前更常见的查看路径是：

1. 进入 `牌库`
2. 打开对应牌组
3. 点进那张具体卡片
4. 再点页面里类似 `规划 x 天后复习 >` 的入口

论坛互助里给出的公开演示显示，这里可以进入卡片的 `记忆历史` 页面。

## 这页通常能帮你看什么

论坛里围绕这条入口，最常提到的是这几类信息：

- 这张卡之前点过哪些反馈
- 当前显示的下次复习安排
- 某些版本里还能看到对应的遗忘曲线信息

如果你是想弄清楚“为什么这张卡会被安排到几十天后”，这页通常比只盯着按钮上的天数更有帮助。

## 什么时候特别值得先看这里

- 你觉得某张卡的间隔明显过长
- 你想确认自己是不是之前连续点过很多次 `认识`
- 你准备给官方反馈某张卡的复习安排异常

## 如果你准备反馈问题

论坛里较新的官方回复已经明确提到过：

- 先找到这类你觉得安排异常的卡片
- 把相关 `记忆历史` 信息截图
- 再连同账号信息一起发给 `support@markji.com`

这样工程师更容易做针对性排查。

## 如果你一时找不到这个入口

先确认两件事：

- 你是不是在 `单张卡片详情页` 里找，而不是只在牌组列表页找
- 你当前 App 是否已经更新到较新的版本

论坛里这条入口的公开演示主要来自 2026 年 5 月的讨论，所以如果你的界面和帖子截图差很多，先别急着下结论。

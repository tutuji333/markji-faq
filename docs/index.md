# 墨墨记忆卡常见问答

这套 FAQ 不是手册缩写版，而是基于论坛高频讨论整理出来的帮助中心。它主要回答三类问题：

1. 我应该先去哪里求助
2. 这个现象到底是什么意思
3. 出现异常后下一步该怎么做

如果你想看完整教学，请去[使用手册](https://tutuji333.github.io/markji-manual/)。

## 这套 FAQ 当前覆盖什么

基于目前的论坛讨论，FAQ 重点覆盖这些高频主题：

- 一键选卡为什么看不到
- 如何保证每日固定新学量
- `认识 / 模糊 / 忘记` 应该怎么按
- 重置学习数据和移出记忆有什么区别
- 单张卡片能不能直接移到另一个牌组
- 收藏牌组能不能自由编辑
- 收藏牌组在原作者删除后会不会消失
- 终身会员如何升级
- 专业版里的“更大容量”是什么意思
- 为什么不能自己设置牌组学习消耗
- `apkg` 导入失败、Anki 导入失败或乱码怎么办
- 网页端如何精准搜索
- 签到失败或找不到补签入口怎么办

## FAQ 的边界

- 这里优先写高频结论，不写长篇讨论过程
- 这里优先回答“为什么会这样”和“下一步该做什么”
- 需要完整路径教学时，直接跳到使用手册
- 仍在变化中的能力，以当前应用内入口、版本说明和官方回复为准

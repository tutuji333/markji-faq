# Anki 导入失败或乱码怎么办？

## 简答

如果你已经遇到的是：

- 不勾旧版本支持就导不进去
- 勾了旧版本支持后能导进去，但内容全是乱码
- 明明模板很简单，还是导入异常

论坛里较新的官方口径是：**直接把相关文件发给 `support@markji.com`，官方会安排工程师针对具体文件排查并协助导入。**

这页更像“准备好文件，走人工排查”的入口，而不是一套纯自助修复步骤。

## 为什么这类问题不适合继续猜格式

因为这已经不是“看一眼设置就能确定”的问题了。

论坛里同类讨论最终给出的处理方式，都是回到：

- 把文件交给官方
- 让工程师针对这一个文件具体排查

## 发邮件时最好一起附上

- 需要导入的 Anki 相关文件
- 你试过的导出方式
- 报错截图
- 你当前使用的设备和版本

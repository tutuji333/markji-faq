# 登录时提示“学习数据解压密码错误”怎么办？

## 简答

如果你已经确认：

- 用的是较新的版本
- 换设备试过还是不行

论坛里给出的官方处理方式是：**直接邮件联系 `support@markji.com`。**

这类问题本质上更像 `账号与数据人工排查`，不是靠论坛里多试几个按钮就能解决的普通故障。

## 官方希望你一起提供什么

- 墨墨注册账号
- 出问题的设备型号
- 错误截图

这类问题已经涉及账号和数据，论坛不适合继续展开。

## 为什么不建议只在论坛发帖

因为这类问题通常需要：

- 结合账号信息排查
- 做更深入的数据定位
- 注意隐私和安全

所以它更像客服和技术一起处理的问题，不像普通操作问答。

# 单张卡片能直接移到另一个牌组吗？

## 简答

按论坛里的官方邮件口径，**当前版本还不支持直接跨牌组移动单张卡片**。

## 为什么很多人会卡在这里

因为复制粘贴虽然能把内容搬过去，但会带来两个常见问题：

- 新卡不会继承原来的记忆历史
- 旧卡删不删，都会让人陷入取舍

所以这不是一个“只是麻烦一点”的问题，而是当前能力本身还没有补齐。

## 论坛里后来补充过的原因解释

较新的官方回复提到，这件事不只是“防不防盗版”那么简单。

更底层的前提其实是：

- 先把 `用户个人牌库` 和 `共享牌组` 做逻辑隔离
- 再把 `牌组版本控制` 这套能力补起来

也就是说，它之所以迟迟没有直接放开，更像是底层内容结构和共享更新体系还没完全准备好。

## 现在能怎么绕

如果你只是想补充内容，通常更稳妥的做法是：

- 先保留原卡
- 在新牌组里重新建卡
- 接受这是两张不同卡，不把它当成“无损移动”

## 当前结论

如果你的核心诉求是“连同记忆历史一起把单卡搬过去”，论坛现有口径并没有给出可直接实现的正式办法。

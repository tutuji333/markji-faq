# 为什么图片遮盖更适合在网页端处理？

## 简答

论坛里的官方回复很直接：**如果你要对图片卡做二次遮盖，网页端通常比手机端更合适。**

## 原因是什么

官方给出的解释是：

- 手机端受屏幕空间和操作逻辑限制
- 二次编辑图片遮盖时不够方便
- 网页端的遮盖处理更高效、也更完整

## 现在更稳妥的做法

如果你要改的是别人牌组里的图片卡，优先试试官方网页端：

- `www.markji.com`

## 适合什么场景

- 别人的图片卡你想自己再挖空一次
- 手机端里找不到合适的遮盖入口
- 你需要更精细地改遮盖范围

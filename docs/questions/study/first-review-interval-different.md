# 为什么同一天新学的卡片，初次点认识后复习间隔不同？

## 简答

这是正常情况，不一定是卡片或算法出了问题。

官方在论坛里解释过：每张卡片的复习间隔不是固定统一的。系统会综合考虑你的个人记忆情况、卡片难易程度，以及未来的复习压力。

所以，即使几张卡都是今天新学、第一次反馈都点了 `认识`，下一次复习也可能分别被安排到 5 天、7 天或其他接近的时间。

## 为什么会这样安排

一个重要原因是：系统会尽量避免未来某一天的复习任务集中爆发。

如果同一天新学的卡片全部安排到完全相同的下次复习日，之后可能在某一天一起到期，让复习压力突然变大。系统会在合理的复习间隔区间内，把这些卡片智能分散到不同日期。

因此，“同一天新学 + 同样点认识”并不代表所有卡片都必须得到完全一样的下次复习间隔。

## 什么时候需要进一步反馈

如果只是相差几天，通常可以先按正常安排理解。

如果你遇到的是下面这类情况，更适合去反馈：

- 大量新卡的间隔明显超出正常理解范围
- 某一张卡的安排和你的记忆历史明显对不上
- 你看到的按钮间隔、记忆历史和实际到期时间互相矛盾

反馈前可以先准备：

- 相关卡片截图
- 记忆历史截图
- 你当天具体点了 `认识 / 模糊 / 忘记` 中的哪个按钮
- 你看到的下次复习天数

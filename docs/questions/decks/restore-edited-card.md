# 修改过的卡片如何恢复？

## 简答

论坛里的口径分成两段：

- 早期：官方明确说过，**收藏卡片复原**当时还不支持
- 后来：同一条问题又被官方回链到“已支持 `卡片编辑历史`”的新讨论

## 现在更应该先看哪里

目前论坛里公开展示最清楚的入口，是官网网页端的 `卡片编辑历史`：

- 可以查看一张卡片的历史编辑记录
- 可以回看历史版本
- 可以把卡片还原到某个旧版本

如果你现在想找“恢复入口”，优先先去网页端找 `编辑历史`。

## 这页最容易误解的地方

论坛里公开演示得最明确的，是**网页端、自建牌组卡片**的编辑历史能力。

所以更稳妥的理解是：

- 公开可见的稳定入口，在网页端
- “已支持卡片编辑历史”这件事已经被官方明确提过
- 但不要自动把它理解成“所有端、所有场景、所有收藏卡片入口都完全一样”

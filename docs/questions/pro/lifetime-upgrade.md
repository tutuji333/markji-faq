# 终身会员如何升级？

## 简答

论坛里较新的官方邮件口径是：

路径：`我的 -> 右上角礼物图标 -> 福利活动`

目前提到的升级条件是：`专业版剩余天数大于 999 天`。

## 这页最需要知道的两点

- 升级入口不在 FAQ、论坛或网页里，而是在 App 内的 `福利活动`
- 官方当时明确写过具体条件，不是所有专业版用户都能直接点一下就升级

## 官方给过的一个建议

在那封邮件里，官方还额外提到：

- 通常不建议直接一步升终身
- 更建议先用月卡确认自己是否真的适合这套产品和权益

这不是限制条件，而是官方给出的使用建议。

# 复习时应该如何点击“认识 / 模糊 / 忘记”？

## 简答

最关键的一条是：**先尝试自己回忆，再按照当下的真实记忆状态点击。**

不要把流程变成“先背熟，再统一点认识”。

## 为什么“先背熟再一直点认识”不合适

论坛里的官方解释很明确：

- 这样会绕开主动回忆
- 算法会误以为你掌握得比实际更牢
- 后面的复习间隔可能被安排得过长

结果就是：你以为自己在“稳一点”，实际可能反而更容易在后面断档。

## 更推荐的使用顺序

1. 看到问题，先试着回忆
2. 根据第一反应判断自己是 `认识 / 模糊 / 忘记`
3. 点击真实反馈
4. 再借这一次机会看答案、巩固、补记

也就是说，**复习结果要真实，巩固动作可以发生在点击之后。**

## 一个简单判断

如果你每次都是：

- 不管记不记得，都先重新背熟
- 然后再点 `认识`

那通常就不是这套算法最理想的用法。

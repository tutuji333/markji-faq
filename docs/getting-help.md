# 我该去哪里求助？

先判断你遇到的是哪一类问题，再走对应入口。

## 我想提新功能或改进建议

路径：`App -> 我的 -> 帮助与反馈 -> 功能许愿`

- 适合：新功能、交互改进、希望支持某种能力
- 更稳妥的做法：一次只提一个愿望，最好附图
- 不建议：把功能愿望发去客服邮箱，官方在服务指南里明确说这类邮件通常不会按人工协助处理

## 我遇到的是 bug、异常、按钮不对、闪退或网页行为异常

优先走 `异常反馈`：

- App：`我的 -> 帮助与反馈 -> 异常反馈`
- 网页端：右下角 `?` -> `异常反馈`

这是产品侧最适合排查异常的入口，因为会自动附带设备和运行信息。论坛发帖通常拿不到这些信息，更适合互助，不适合真正定位 bug。

## 我遇到的是账号、登录、同步、订单、文件迁移，或需要人工直接协助

发邮件到：`support@markji.com`

建议一起附上：

- 注册账号
- 设备型号
- 系统版本和 App 版本
- 报错截图或录屏
- 如果和导入有关，直接附上出问题的文件

## 我想先看看别人有没有问过类似问题

先搜这套 FAQ，再去论坛看历史讨论：

- [学习与复习](study-cards.md)
- [牌组与卡片](decks-cards.md)
- [签到与反馈](account-sync.md)
- [专业版与记忆币](pro-membership.md)
- [导入与迁移](import-export.md)
- [网页版、语音与搜索](web-editing.md)

论坛更适合看别人怎么理解、怎么用、有哪些变更公告，不适合替代异常反馈或客服邮箱。

## 我想改的是这套 FAQ 本身

如果你想反馈的是文档错误、表达不清、过时答案或缺失条目：

- 用页尾的 `Issue / PR / 文档邮箱`
- 不要把“文档纠错”当成产品 bug 提给官方异常反馈

## 一句话判断

- 新功能：`功能许愿`
- 软件异常：`异常反馈`
- 账号 / 文件 / 人工协助：`support@markji.com`
- 看讨论和公告：`论坛`
- 改 FAQ：`Issue / PR / 文档邮箱`

# 墨墨记忆卡常见问答

这套站点只处理三类内容：

1. 高频短问题
2. 求助前应该先看什么
3. 报错、失败、异常时应该怎么处理

如果你想看完整的功能说明，请去[使用手册](https://tutuji333.github.io/markji-manual/)。

## 这套 FAQ 的边界

- 这里只写稳定的高频结论，不写论坛讨论过程
- 这里优先回答“为什么会这样”和“下一步该做什么”
- 需要完整教学时，直接跳到使用手册
- 仍在变化中的能力，以产品页、版本说明和应用内入口为准

## 当前优先覆盖的问题

- 一键选卡为什么看不到
- 重置学习数据和移出记忆有什么区别
- 终身会员如何升级
- 学习收藏牌组消耗减免是什么意思
- 为什么不能自己设置牌组学习消耗
- `apkg` 导入失败或 PDF 导出不完整怎么办

# 为什么有些卡片的复习间隔会突然很长？

## 简答

论坛里目前能看到的解释，主要有两种：

- `算法按你的反馈正常放大了间隔`
- `某些旧版本 / 旧算法阶段，确实出现过间隔异常偏长的已知问题`

所以看到几十天、几百天甚至更长，不一定直接等于出 bug，先要看它是怎么长出来的。

## 哪些情况更像正常增长

论坛公开解释里，一个很常见的场景是：

- 系统原本安排的间隔不长
- 但你实际隔了很久才再次见到这张卡
- 这次你仍然点了 `认识`

这时算法会倾向于认为：你对这张卡的掌握其实比系统原先估计得更牢，于是下一次间隔会明显拉长。

[topic 599](https://markji.discourse.group/t/topic/599) 里就给过这种解释。

另一种更常见的情况是：

- 你总是先重新背熟，再统一点 `认识`

论坛在 [topic 146](https://markji.discourse.group/t/topic/146) 里反复提醒过，这样会让算法高估你的真实掌握程度，后面安排出来的间隔也可能越来越长。

## 如果你觉得间隔太长，先怎么处理

论坛里更一致的建议是：

1. 先别硬点 `认识`
2. 如果你主观上觉得这张卡还不够稳，直接点 `模糊`
3. 打开反馈按钮的间隔显示，边学边看系统给你的下次安排
4. 需要时去看这张卡的 `记忆历史`

[topic 483](https://markji.discourse.group/t/topic/483) 和 [topic 599](https://markji.discourse.group/t/topic/599) 都提到，`模糊` 是一个很直接的“把间隔拉回稳一点”的办法。

如果你不知道从哪看，先看：

- [如何查看卡片记忆历史与下次复习安排？](memory-history.md)

## 什么时候更像版本 / 算法问题

[topic 599](https://markji.discourse.group/t/topic/599) 里还出现过另一类说明：

- 某些用户曾遇到 `1000+ 天` 这种明显过长的安排
- 官方当时提到过 `MMX-5.1` 作为优化方向

这类情况更适合这样判断：

- 如果只是个别卡片、且你的历史反馈本来就偏“认识”，先按正常逻辑理解
- 如果大量卡片都突然出现极端长间隔，再去看版本、算法更新和是否需要反馈

## 如果你是考前阶段

这类问题不要只盯着“下一次安排是多少天后”，还要看你的目标是不是短期冲刺。

如果你是临近考试，更实用的做法通常是：

- 复习时更真实地选 `模糊 / 忘记`
- 需要时配合 `练习模式`
- 少量结合 `提前复习`

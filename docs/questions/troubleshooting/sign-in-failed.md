# 签到失败或按钮异常怎么办？

## 先判断是“没看到入口”，还是“真正失败”

先把这两种情况分开：

- `规则 / 入口问题`：比如找不到补签按钮、想知道提前签到有什么用
- `真正异常`：比如已经满足条件却签到失败、只有某个端签不了、行为明显不符合预期

如果你是第一种，先看：

- [补签按钮在哪里？补签卡怎么用？](../sign-in/make-up-sign-in.md)
- [提前签到有什么用？](../sign-in/early-sign-in.md)

论坛里能明确确认的两个细节是：

- `补签` 按钮通常要在**完成当天学习计划后**，并且系统判断你满足补签条件时才会出现
- `提前签到` 的公开讨论，目前只明确提到了 `iOS 4.13.00` 的新增入口

## 如果是真正异常

论坛里的处理口径很一致：**优先走异常反馈，不要只停留在论坛发帖。**

更稳定的官方路径是：

- App：`我的 -> 帮助与反馈 -> 异常反馈`

论坛的其他讨论里，也出现过网页端 `? -> 异常反馈` 的说法；如果你当前网页端确实能看到这个入口，也可以直接用，但更稳定的官方口径仍然是 App 内异常反馈。

## 为什么要这样处理

因为签到失败通常需要结合：

- 设备信息
- 版本号
- 具体异常截图
- 是否跨设备复现

这些信息论坛里拿不到，异常反馈才更适合做真正排查。

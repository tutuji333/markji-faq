# 学习收藏牌组消耗减免是什么意思？

## 简答

按 `2026-05-09` 那封官方邮件的现行口径，升级 Pro 之后：

- 学自己的牌组：`免记忆币消耗`
- 学别人做的收藏牌组：`仍要消耗记忆币，但减半`

## 这页最容易搞混的一点

很多人会把“系统里搜到的牌组”理解成平台内容，不知道算不算别人做的牌组。

按论坛里的官方邮件口径，这类通过搜索后收藏来学的牌组，仍然属于 `收藏牌组`，不是你的自建牌组。

所以开了 Pro 之后，它不是全免，而是 `50% 减免`。

## 但这条规则目前正处在变化期

论坛在 `2026-05-14` 的商业模式前瞻里又明确说过：

- 团队计划让基础学习行为不再消耗记忆币
- 历史收藏的公开牌组，未来计划直接视同已获得完整学习权

所以这页更准确的理解应该是：

- 它解释的是**旧商业模式下，这句话当时是什么意思**
- 它**不是**一个已经确认长期不变的最终规则

## 一句话区分旧口径

- 你自己建、自己维护：免费
- 别人建、你收藏来学：减半，不是全免

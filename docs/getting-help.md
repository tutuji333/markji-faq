# 我该去哪里求助？

先分清你遇到的是“功能建议”“软件异常”还是“账号 / 人工协助”，再走对应入口。

## 我想提新功能或改进建议

路径：`App -> 我的 -> 帮助与反馈 -> 功能许愿`

- 适合：新功能、交互改进、希望支持某种能力
- 官方在论坛里反复强调：一次只提一个愿望，最好附图
- 不建议：把功能愿望直接发去客服邮箱

## 我遇到的是软件异常、bug 或明显不符合预期的行为

更稳定的官方口径是：**先走 App 内 `异常反馈`**。

路径：`App -> 我的 -> 帮助与反馈 -> 异常反馈`

- 适合：闪退、卡顿、功能异常、签到失败、网页行为异常、导入异常
- 如果是 `跨设备同步失败`，论坛里的官方建议也是先走这里，再视情况补邮件
- 如果和导入有关，最好把原文件一并保留，方便后续排查

## 我遇到的是账号、登录、数据、文件迁移，或需要人工直接协助

发邮件到：`support@markji.com`

更适合邮件处理的典型情况包括：

- 登录时提示 `学习数据解压密码错误`
- 需要提供账号信息做一对一排查
- 文件迁移或其他需要人工跟进的情况

建议一起附上：

- 注册账号
- 设备型号
- 系统版本和 App 版本
- 报错截图或录屏
- 如果和导入有关，直接附上出问题的文件

## 我想改的是这套 FAQ 本身

如果你想反馈的是文档错误、表达不清、过时答案或缺失条目：

- 用页尾的 `Issue / PR / 文档邮箱`
- 这属于 FAQ 站点维护入口，不是产品官方反馈渠道

## 一句话判断

- 新功能：`功能许愿`
- 软件异常：`异常反馈`
- 跨设备同步：先 `异常反馈`，再按需要补邮件
- 账号 / 登录 / 数据排查：`support@markji.com`
- 看讨论和公告：`论坛`
- 改 FAQ：`Issue / PR / 文档邮箱`

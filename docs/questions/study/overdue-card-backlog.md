# 卡片大量逾期堆积怎么办？

## 简答

如果逾期卡片已经堆得很多，官方更推荐的处理方式是：**先用 `提前签到` 稳住打卡状态，再用 `继续复习` 分批消化逾期卡片**。

不要因为一时压力太大，就优先去重置整个牌组的学习数据。重置会清空已有学习进度，除非你已经明确决定从头开始，否则要谨慎使用。

## 为什么不能直接把逾期卡片标记为遗忘？

官方在 [topic 740](https://markji.discourse.group/t/topic/740) 里说明：在目前的学习逻辑中，已经逾期的卡片会被自动归入 `今日待复习` 范围内，所以系统目前无法对已逾期卡片直接标记 `遗忘`。

这意味着，如果你想处理的是已经堆积到今天的逾期任务，当前更现实的办法不是“批量遗忘”，而是分批把它们复习掉。

## 推荐怎么处理

可以按这个顺序来：

1. 先使用 `提前签到`，避免因为当天学不完而产生额外签到压力。
2. 根据当天精力，只复习一个你能接受的数量，不要硬撑到精疲力尽。
3. 完成基本任务后，使用 `继续复习`，按牌组分批处理剩余逾期卡片。
4. 后续几天继续用同样方式慢慢清，不要指望一天把大量积压全部解决。

如果你不熟悉 `提前签到`，可以先看：

- [提前签到有什么用？](../sign-in/early-sign-in.md)

## 重置学习数据还能用吗？

还能用。官方说明里提到，`重置学习数据` 入口因为防误触放到了较深的位置：

`我的` → `更多设置` → 页面底部 → `重置学习数据`

但要注意：这个功能会一次性清空牌组学习数据，让之前的记忆进度丢失。除非你确实想把牌组当作完全没学过来重新开始，否则更建议先尝试 `提前签到 + 继续复习`。

## 会有“分散复习压力”功能吗？

官方在同一条帖子里回复过：类似“分散复习压力”的能力已经纳入产品优化考虑，但由于研发排期原因，当前优先级很低，预计会在后续 `6.0+` 交互大版本中结合整体体验再评估和规划。

所以现阶段不要把解决方案建立在“马上会上线新功能”上，还是优先按当前可用的 `提前签到 + 继续复习` 来处理。

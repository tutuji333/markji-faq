# 故障排查

这页只处理异常、失败、报错和恢复动作。

## 真正遇到软件异常时，先走哪里反馈

论坛里“签到失败”等异常帖反复提到一个原则：

- `报 bug / 软件故障`：优先走应用内 `异常反馈`
- `提建议`：走 `功能许愿`
- `需要人工协助`：走邮件
- `想讨论或互助`：走论坛

如果你只是把异常发到论坛，别人可能能帮你判断方向，但真正排查 bug 仍然更依赖应用内反馈带上的设备信息。

## 排查顺序

1. 先确认症状是什么
2. 再确认平台和版本
3. 再确认是否可稳定复现
4. 如果仍未解决，再准备反馈材料

## 当前优先排查的症状

### 导入 `apkg` 时提示“文件解析失败，请更换其他文件”

可能原因：

- 文件损坏
- 当前文件不在支持范围内
- 平台或版本差异

建议动作：

- 换一个确认可用的示例文件复测
- 记录平台、版本和具体报错
- 保留源文件以便后续排查

### PDF 导出不完整

可能原因：

- 内容过长
- 图片或公式影响导出
- 特定端的导出行为不一致

建议动作：

- 先在当前端预览完整内容
- 缩小测试范围，确认是个别卡片还是普遍问题
- 记录导出前后的差异截图

### 登录后无法正常进入或提示异常

可能原因：

- 登录方式变化
- 账号状态异常
- 网络或设备切换导致状态不一致

建议动作：

- 确认账号、平台、版本
- 确认是否最近切换过设备
- 保留报错截图和复现路径

### 签到失败或看不到签到结果

如果你遇到的是签到失败、换设备后行为不一致、或者只有部分端能签到：

可能原因：

- 端与端之间的版本或实现差异
- 当前账号状态异常
- 某一端的运行环境问题

建议动作：

- 先记录到底是“所有端都失败”，还是“只有某一端失败”
- 记录平台、系统版本、App 版本和出现时间
- 优先通过应用内 `异常反馈` 提交，而不是只在论坛描述

## 联系支持前建议准备

- 当前平台和版本号
- 问题发生路径
- 截图或录屏
- 是否可稳定复现
- 是否和导入文件、牌组或账号有关

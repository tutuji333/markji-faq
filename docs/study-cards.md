# 学习、复习与选卡

这页处理学习过程里的高频问答。

## 常见问题

### 为什么一键选卡看不到

先检查：

- 当前平台是否支持
- 当前版本是否支持
- 当前入口是否正确
- 当前牌组状态是否满足前置条件

如果你已经确认入口没问题但仍看不到，继续看[故障排查](troubleshooting.md)。

### 为什么学习量看起来不对

常见原因包括：

- 今日新学量和手动超额加入不是一回事
- 复习上限可能影响新学表现
- 自动选卡和手动选卡的行为边界不同

更完整的解释请看[使用手册的学习与复习页](https://tutuji333.github.io/markji-manual/study-review/)。

### `认识 / 模糊 / 忘记 / 熟知` 应该怎么选

先按真实记忆状态选，不要按“想让算法怎么安排”倒推。

- `认识`：当前能回忆
- `模糊`：能想起但不稳
- `忘记`：当前没回忆出来
- `熟知`：已经完全掌握

### 重置数据和移除记忆有什么区别

它们不是同一个层级的动作。

在你还没完全确认前，不建议直接做影响学习记录的操作。涉及学习记录时，最好先确认同步边界和备份方式。

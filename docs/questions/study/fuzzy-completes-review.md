# “模糊完成复习”是什么意思？

## 简答

这个选项决定的是：你点击 `模糊` 时，今天这张卡算不算已经完成复习。

- `关闭`：一直点 `模糊` 也不算完成，卡片会继续出现
- `开启`：点 `模糊` 也能完成当天复习

## 官方更推荐哪种状态

论坛里的官方说明是：**更推荐保持关闭**。

原因是，算法更希望你在真正认识时再给出明确反馈，这样后续安排才更稳。

## 为什么很多人会纠结这个开关

因为它会直接影响当天任务能不能结束：

- 如果你只想尽快做完今天的任务，开启会更宽松
- 如果你更重视记忆质量，关闭会更严格

## 更简单的判断方式

如果你希望：

- `模糊` 只是“先别放过这张卡” -> 关掉
- `模糊` 也能算今天先过一遍 -> 打开

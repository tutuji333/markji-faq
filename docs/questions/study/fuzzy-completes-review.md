# 为什么“模糊完成复习”功能不见了？

## 简答

这个设置原本的作用是：点击 `模糊` 时，也允许这张卡**完成当天复习**。

但根据论坛里的最新官方回复，这个功能已经被**下线并删除**，当前**没有恢复计划**。现在不应该再把它理解成一个还可以开启或关闭的现有选项。

## 官方目前给出的解释

论坛官方的最新口径是：

- 这个设置此前属于一项用户实验，不是长期保留的稳定功能
- 团队认为实验结果显示，这个设置会对长期记忆效果产生负面影响
- 团队因此决定直接下线该设置，当前没有恢复计划

官方还补充提到，他们做过线上实验，结论是这项调整没有拉低留存，三十日留存反而提高了。

## 现在的复习逻辑，最容易被误解的地方

论坛里后来又补充说明了两点：

- 一张卡在当天的**第一次反馈**，才会影响它下一次长期复习间隔
- 当天后续重复出现时的反馈，只会影响这张卡**今天还要不要再出现几次**

也就是说，当前并不存在一套“先点模糊做更细分类，后面系统再额外安排高配复习”的隐藏机制。

## 如果你之前就是靠这个功能控制节奏

目前没有可恢复的开关。按论坛官方现口径，更现实的做法是：

- 接受这个功能已经取消，不再按旧教程寻找入口
- 如果总被少数难卡卡住，优先检查卡片内容、表述方式和拆分粒度
